# NER-AEGIS - AI Landslide Early Warning for NER
**SIH2026 | PS ID: SIH26001 | Organization: MDoNER | Theme: Disaster Management**

> Real-time AI + GIS platform to predict landslides in North Eastern Region before they happen.

### Problem
NER faces 65% of India's landslides. Current system is reactive & manual.

### Solution
AI model (Rainfall + Slope + Soil Moisture + Satellite) -> GIS Risk Heatmap -> Multilingual SMS Alert -> Crowdsourced field reporting with offline PWA.

### Tech Stack
Frontend: React + Mapbox | Backend: FastAPI + PostGIS | AI: RandomForest + LSTM | APIs: IMD, Bhuvan, Bhashini
